Integration Guide

              
Agent Requirements

            


            

              

                CLI contract
                
에이전트 모듈은 `python -m module --input scenario.json --drift-mode mode --output result.json --review-output review.json` 형태로 실행되어야 합니다.

              

              

                Agent result
                
`--output` 파일에는 에이전트 실행 결과 JSON을 저장합니다. 화면의 JSON 탭에서 원본 결과를 확인할 수 있습니다.

              

              

                Review request
                
`--review-output` 파일에는 DriftGuard `POST /v1/agent-reviews`에 보낼 요청 JSON을 저장해야 합니다.

              

              

                Paths
                
`working_directory`, `python`, `scenario input`은 모두 backend 폴더 기준 상대경로여야 합니다.
